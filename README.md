# PheniksPack

**Твой Minecraft. Твои правила.**

PheniksPack — адаптивный каталог ресурспаков для Minecraft.

## Что внутри
- Каталог с поиском и фильтрами по категориям
- Избранное с сохранением в браузере
- Инструкция по установке ресурспаков
- Адаптивный интерфейс для компьютеров и телефонов

## Локальный запуск
Открой `index.html` в браузере. Для разработки можно использовать расширение Live Server.

## Добавление настоящих ресурспаков
Сейчас карточки в каталоге демонстрационные. Чтобы опубликовать настоящий пак:
1. Добавь ZIP-файл в репозиторий, например в папку `packs/`.
2. Добавь карточку в массив `packs` в `script.js`.
3. Укажи ссылку на ZIP и замени статус «Скоро» на кнопку скачивания.

## Публикация
В настройках репозитория открой **Settings → Pages**, выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажми **Save**.
